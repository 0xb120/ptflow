ptflow · pipeline webscan

signal / flow

Le loop di web-DEPTH di external su una lista di target web PRE-AGGREGATA (scheme://host[:port]): salta scope expansion, scan di rete attivo e OSINT per-app. Un solo step di breadth (ingest: httpx che onora lo scheme), poi crawl → catalogo → DAST → fuzz identici a external (ne riusa le funzioni immutate). È il profilo 'external web' a cui la pipeline internal fa hand-off. Ogni stage comunica solo via file su disco.

FASE 1 (coda) — assembla il CATALOGO della SUPERFICIE ESPLORABILE (requests.jsonl): richieste COMPLETE (metodo/body/json/header, non solo URL).
