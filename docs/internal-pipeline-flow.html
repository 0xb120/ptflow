portscan

needs discover

BREADTH — naabu sul set curato di porte di servizio interne (INTERNAL_PORTS, ~100 TCP: SMB/LDAP/RDP/DB/UI di mgmt) sugli host live → ports.jsonl. Whole-scope + rate-controlled: UNA passata gentile invece di N flood per-subnet (gear legacy/OT è fragile).

naabu -silent -p <INTERNAL_PORTS> -c <conc> -rate <rate> # rate/conc = profilo # parse_naabu: righe ip:port → [{ip, port}]
asset_discovery/ports.jsonl
  • rate=profilo (wide 1000/50 · home 300/20) · SNMP è UDP/161 → lo sonda snmp_checks, non qui
  • carico aggregato ≈ concorrenza x rate: il rate è la leva reale su una linea vincolata
  • cluster() affetta ports.jsonl per subnet dopo — scan whole-scope, output per-subnet
